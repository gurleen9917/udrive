# 🚗 U Drive - Professional Full-Stack Vehicle Rental Platform

U Drive is a production-grade, MERN stack vehicle rental application built for a professional portfolio. It features secure user authentication, a multi-category vehicle catalog (cars and bikes), real-time price calculations, and complete CRUD booking management.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, React Router, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose ODM
* **Security:** JSON Web Tokens (JWT), bcryptjs password hashing

## ✨ Key Features
* **Secure Authentication:** User registration and login protected by password hashing and session tokens.
* **Multi-Category Catalog:** Dynamically organized inventory sections for Sedans, SUVs, Luxury cars, and Bikes.
* **Live Date-Math Calculator:** Real-time rental duration and price calculation on the booking screen.
* **Full CRUD Operations:** Create, view, and delete reservations seamlessly from a dedicated dashboard.
* **Responsive UI/UX:** Clean, modern landing page with a hero background and instant client-side search filtering.
